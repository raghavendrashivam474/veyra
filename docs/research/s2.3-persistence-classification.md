# S2.3 Research Note — Stable vs. Transient Identity Characteristics

## 1. Context & Strategic Problem
In character identity modeling, visual perception produces observations across diverse scenes and references. An image containing a character smiling outdoors in a red jacket contains both **essential identity markers** (facial structure, eye shape) and **ephemeral situational traits** (expression, jacket, background, daylight).

S2.3 addresses the foundational identity question:
> **Which characteristics belong to persistent character identity, and which are allowed to vary across scenes and narrative contexts?**

Prematurely forcing all observed visual traits into a monolithic character schema destroys the system's ability to maintain identity consistency while allowing scene variation.

---

## 2. Persistence Semantics & Taxonomy

S2.3 introduces a formal categorization without freezing an inflexible ontology:

| Category | Definition | Exemplar Namespaces / Traits |
| :--- | :--- | :--- |
| `STABLE` | Invariable physical identity characteristics defining who the character is across all contexts. | `facial.*`, `bone_structure.*`, `skin.tone`, `skin.undertone`, `body.proportions` |
| `TRANSIENT` | Ephemeral, situational attributes expected to vary freely between images and scenes. | `style.clothing`, `pose.*`, `lighting.*`, `expression.*`, `scene.*` |
| `CONTEXT_DEPENDENT` | Characteristics persistent within a specific narrative arc or episode, but modifiable over time. | `hair.color`, `hair.length`, `hair.texture`, `facial_hair.style`, `body.tattoos` |
| `UNKNOWN` | Unclassified, novel, or ambiguous traits requiring further perception data or user guidance. | Novel namespaces, experimental perception outputs |

---

## 3. Persistence Domain Model

Defined in `src/veyra/domain/persistence.py`:

```python
@dataclass(frozen=True, slots=True)
class ClassifiedTraitAssessment:
    assessment: TraitAssessment
    persistence: PersistenceCategory
    classification_rationale: str
```

### Key Invariants:

1. **Explainable Rationale**: Every classification decision carries a mandatory, human-readable classification_rationale.
2. **Complete Evidence Transparency**: Retains the inner TraitAssessment with all supporting/conflicting EvidenceRecord 
   provenance and confidence scores intact.
3. **Semantic Querying**: Provides is_identity_defining, is_transient, and is_ambiguous properties for downstream 
   generation and identity constraint enforcement.

## 4. Baseline Classification Strategy (BaselinePersistenceClassifier)

The default S2.3 classifier evaluates trait namespaces and specific trait names using conservative heuristics:

- facial.*, anatomical.*, bone_structure.* → STABLE
- style.*, pose.*, lighting.*, expression.*, scene.* → TRANSIENT
- Specific modifiable physical features (e.g. hair.color, hair.length) → CONTEXT_DEPENDENT
- Any unmapped trait gracefully defaults to UNKNOWN.
