# S2.1 Research Note — Observation Reconciliation

## 1. Context & Problem Statement
In S1, Veyra established the visual perception layer producing raw `Observation` value objects. A single character represented across multiple visual references (or analyzed across multiple models) will invariably yield:
1. Multiple agreeing observations for a given trait (e.g. `hair.color = dark_brown`).
2. Conflicting observations for the same trait (e.g. `hair.color = dark_brown` vs. `hair.color = black`).
3. Single observations where sparse evidence exists.

S2.1 answers:

> **How do we reconcile multiple observations concerning the same trait into a coherent trait-level state without destroying observation provenance?**

---

## 2. Reconciled Representation Model

We introduced `ReconciledTrait` in the domain layer (`src/veyra/domain/reconciliation.py`):
```python
@dataclass(frozen=True, slots=True)
class ReconciledTrait:
    trait: TraitName
    selected_value: TraitValue
    confidence: Confidence
    supporting_observations: tuple[Observation, ...]
    conflicting_observations: tuple[Observation, ...]
```

### Key Invariants:

- **Full Provenance Preservation**: All supporting and conflicting observations remain attached as immutable tuples.
  No observation    ID, reference ID, source model tag, or evidence payload is discarded.
- **Strict Trait Consistency**: Every observation in supporting_observations and conflicting_observations must belong to trait.
- **Value Separation**: supporting_observations strictly match selected_value; conflicting_observations strictly do not
  match selected_value.
- Immutability: Fully frozen slots dataclass.

## 3. Reconciliation Algorithms Evaluated

### Baseline A: HighestConfidenceStrategy

- Selects the single observation with the maximum confidence score.
- **Tie-breaking**: Deterministically resolves ties via (-confidence, str(value), obs_id).
- **Limitation**: Ignores volume of evidence (e.g. 5 agreeing observations with 0.84 confidence would lose to a single
  noisy observation with 0.85 confidence).

### Baseline B: ConfidenceWeightedStrategy (Default S2.1 Baseline)

- Groups observations by TraitValue.
- Sums confidence weights for each candidate value.
- The value with the highest total confidence weight is selected.
- Reconciled confidence is calculated as:
   net_confidence =(support_winner − (0.5× support_conflicts))/total_support
   bounded in [0.0,1.0].
   When there are zero conflicting observations, the winner's maximum observed confidence is preserved.
- Tie-breaking: Deterministic ordering (-total_weight, -max_conf, str(value)) ensures identical inputs produce
  identical outputs   across executions.

## 4. Integration into Application Layer

RepresentationService was extended with:

- reconcile_observations(observations, strategy=None) -> dict[TraitName, ReconciledTrait]
- reconcile_traits(representation, strategy=None) -> dict[TraitName, ReconciledTrait]

Both preserve full backward compatibility with S0/S1 services and entities.

## 5. Verification & Acceptance Criteria

-  Observations can be reconciled deterministically.
-  Agreeing observations are aggregated without loss of items.
-  Conflicting observations are retained in conflicting_observations.
-  Observation provenance (IDs, sources, evidence dictionaries) survives intact.
